# Mouleeshwaran M - Portfolio Website

A modern, responsive personal portfolio website showcasing my projects, technical skills, certifications, and academic background.

🌐 **Live Demo:** [https://mouleeshwaran2006.github.io/Portfolio/](https://mouleeshwaran2006.github.io/Portfolio/)

---

## 🚀 Features

- **About Me:** Overview of my background as an Information Technology student and aspiring software developer.
- **Skills Showcase:** Interactive presentation of programming languages, libraries, and frameworks.
- **Project Portfolio:** Featured projects with tech stacks and live preview links.
- **Certificates & Achievements:** In-browser preview modal and download links for verified certifications.
- **Resume Download:** Fast one-click download for my updated curriculum vitae.
- **Contact Form & Social Links:** Direct ways to get in touch via email, LinkedIn, and GitHub.
- **Responsive Design:** Polished user experience across mobile, tablet, and desktop screens.

---

## 🛠️ Built With

- **Frontend:** React 19, Vite 6, HTML5, CSS3, Modern ES Modules
- **Backend (Optional API):** Node.js, Express, MongoDB (Mongoose)
- **Deployment:** GitHub Pages (automated via GitHub Actions)

---

## 💻 Local Development

If you'd like to run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Mouleeshwaran2006/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
